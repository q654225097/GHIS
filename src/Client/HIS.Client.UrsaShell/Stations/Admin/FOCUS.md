# 系统管理站群焦点与快捷键规划 (FOCUS)

- **站点默认焦点**：各管理台加载时聚焦主检索过滤框（或角色/模板主列表）。
- **快捷键**：
  - **动态表单站**：`F2` 打开当前选中模板字段设计器（无选中时设计处方动态列）；`F5` 刷新模板与处方列。
  - **用户管理站**：`F2` 呼出新增账号抽屉；`Ctrl+F` 聚焦用户检索框；`F5` 刷新列表。
  - **角色权限站**：`F2` 新建角色；`F3` 为当前角色新增资源权限；`Ctrl+F` 聚焦权限资源检索框；`F5` 刷新角色与权限。
  - **审计日志站**：`F2` 校验密码学哈希链完整性；`F3` 固化防截断外部锚点；`F5` 重新查询审计日志。

角色权限站焦点顺序：角色列表 → 权限资源检索框 → 当前权限行的授权级别按钮（完全/只读/脱敏/隐藏）→ 批量调整按钮 → 新增权限。新建角色抽屉按角色编码、角色名称、数据范围、保存顺序 Tab 移动。
