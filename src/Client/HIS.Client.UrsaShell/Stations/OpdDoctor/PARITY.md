## 2. 开 3 个药的点击/按键路径对比

| 步骤 | 旧界面操作路径 | 新界面键盘优先路径 |
|---|---|---|
| 打开加药 | 点击 `+ 新增处方药品` (1次点击，全屏弹窗遮挡当前处方) | 按 `/` 聚焦行内搜索框（或直接点击） |
| 选第 1 个药并改用量 | 滚动查找 → 点 `+ 选入处方` → 点 `关闭字典` → 找到行点 `编辑` → 改字段 → 点 `保存` (~5 次鼠标跨区移动点击) | 输入关键词 → `↑↓` → `Enter` 加药并自动开启行内编辑 → `Tab` 改用量/频次 → `Enter` 保存并焦点回搜索框 |
| 选第 2 个药并改用量 | 点 `+ 新增处方药品` → 找药 → `+ 选入处方` → `关闭字典` → 点 `编辑` → 点 `保存` (~5 次点击) | 输入关键词 → `↑↓` → `Enter` → `Tab` 改用量 → `Enter` |
| 选第 3 个药并改用量 | 再重复约 5 次点击 | 输入关键词 → `↑↓` → `Enter` → `Tab` 改用量 → `Enter` |
| 提交药师审方 | 点击 `提交药师审方` (1次点击) | 按 `Ctrl+Enter`（或点击主按钮） |
| **合计** | **约 16 次鼠标点击 + 3 次全屏弹窗上下文切换** | **0 次全屏遮罩切换，键盘流闭环完成** |
