# 门诊医生站 (OpdDoctor) — FOCUS

## 快捷键约定
- `1` / `F1`：切换至步骤 1【① 诊断录入】(Tab 0)
- `2`：切换至步骤 2【② 处方开立】(Tab 1)
- `3`：切换至步骤 3【③ 检查检验】(Tab 2)
- `4`：切换至步骤 4【④ 门诊病历】(Tab 3)
- `F2`：叫号下一位候诊患者并自动定位到步骤 1【① 诊断录入】
- `/`（焦点不在文本输入框时）：快速切换至步骤 2【② 处方开立】并聚焦行内药品搜索框
- `↑` / `↓`（在行内药品搜索框内）：切换匹配的药品目录项
- `Enter`（在行内药品搜索框内）：加入当前高亮药品到患者处方并开启行内编辑
- `Ctrl+Enter`：提交当前处方至药师审方
- `Ctrl+S`：保存当前门诊结构化病历并生成 OFD 审签归档包
- `Esc`：关闭行内药品搜索下拉或右侧检查清单抽屉

## 键盘 Tab 与标准化五步临床流程
1. **步骤 1：① 诊断录入 (Tab 0)**：初步诊断输入 -> ICD-10 疾病编码 -> 发病诱因补充 -> 常用高频诊断分类与快捷 Chips -> `"保存初步诊断"` -> `"确立诊断并进入处方开立 (下一步) ➔"`
2. **步骤 2：② 处方开立 (Tab 1)**：诊断依据参考条 -> 行内药品搜索框 (`/`) -> 全部/正常/皮试阻断筛选 -> 处方过滤输入框 -> 处方明细行内编辑控件 / 保存 / 删除 -> 前置自动审方 / `"提交药师审方 (Ctrl+Enter)"` -> 皮试/过敏安全替换 -> `"前往下一步：检查检验 (按 3) ➔"`
3. **步骤 3：③ 检查检验 (Tab 2)**：`+ 新增医技申请` -> 申请单列表 -> 医技冲正退费证明 -> `"前往下一步：书写门诊病历 (按 4) ➔"`
4. **步骤 4：④ 门诊病历 (Tab 3)**：主诉 -> 现病史 -> 联动初步诊断 -> 专科检查（按患者性别适配） -> 右侧实时甲级质控与 OFD 审签状态 -> `"保存并提交审签 (Ctrl+S)"` -> `"就诊核对完毕，完成诊疗 (步骤 5) ➔"`
5. **步骤 5：完成诊疗 (Step 5)**：顶部右侧主按钮 -> 弹出全流程闭环核对抽屉（1诊断 2处方 3检查检验 4病历 5用药安全） -> 确认核对完毕后结束就诊并归档
