# 门诊医生站 (OpdDoctor) — FOCUS

## 快捷键约定
- `F2`：叫号下一位候诊患者
- `Ctrl+S`：保存当前门诊病历并生成审签包
- `/`（焦点不在文本输入框时）：聚焦处方区行内药品搜索框
- `↑` / `↓`（在行内药品搜索框内）：切换匹配的药品目录项
- `Enter`（在行内药品搜索框内）：加入当前高亮药品到患者处方并开启行内编辑
- `Ctrl+Enter`：提交当前处方至药师审方
- `Esc`：关闭行内药品搜索下拉或右侧检查清单抽屉

## 键盘 Tab 顺序
1. 左侧候诊队列搜索框 -> `"叫号下一位 (F2)"` 按钮 -> 队列患者列表项
2. 右侧顶部工作流步骤按钮（①病历 ②处方 ③检查检验 ④床位参考）与 `"完成诊疗"` 主按钮
3. **门诊病历 Tab**：主诉 -> 现病史 -> 初步诊断 -> 专科检查（按患者性别显示适配输入） -> `"保存并提交审签 (Ctrl+S)"`
4. **处方 Tab**：行内药品搜索框 (`/`) -> 全部/正常/皮试阻断筛选 -> 处方过滤输入框 -> 处方明细行内编辑控件 / 保存 / 删除 -> `"提交药师审方 (Ctrl+Enter)"`
5. **检查检验 Tab**：`+ 新增医技申请` -> `WHO 手术三方核查` -> 申请单列表
