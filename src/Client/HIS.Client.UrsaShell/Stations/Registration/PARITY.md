# 门诊挂号与收费功能对等清单 (Registration)

> 对应旧版 `RegistrationCashierViewModel`（既有患者检索、号源选择、门诊挂号收款、退号退款、排班入口），以及 v2 §4.10 登录后按角色进入对应站点。

| 旧版能力 | 新站对应实现 | 状态 |
|---|---|---|
| 患者姓名/病历号检索与患者选择 | 左侧患者检索框、结果列表与患者摘要 | 已覆盖 |
| 日期、科室、医生号源查询 | 号源查询条、按可用余额筛出号源 | 已覆盖 |
| 号源选择、应收金额与收款方式 | 号源摘要、金额与收款方式下拉框 | 已覆盖 |
| 挂号收款并推送候诊队列 | “确认收款并挂号”主按钮，沿用 `SettleAsync` | 已覆盖 |
| 挂号记录查询与筛选 | 今日挂号记录列表与关键词检索 | 已覆盖 |
| 退号退款与原因记录 | 退号区、退款原因、二次确认 | 已覆盖 |
| 排班管理入口 | 管理员可见“排班管理”，进入号源排班站 | 已覆盖 |
| 前往处方收费 | “前往处方收费结算”进入财务站 | 已覆盖 |
| 无挂号收费权限提示 | 页面顶部就地显示权限拦截原因，主按钮禁用并说明原因 | 已覆盖 |

数据来源沿用现有门诊挂号接口，未新增服务端端点。实际按钮状态由 `CanSettle`、`CanRefundSelected`、`CanOperateFinance` 计算，不伪造挂号或收费数据。
